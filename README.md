# Subhajit Mahata — 3D Animated Portfolio

A modern, 3D animated personal portfolio website built with React, Three.js, and Framer Motion.

## 🚀 Features

- **3D Hero Section** — Interactive Three.js particle field with floating wireframe geometries
- **Smooth Animations** — Framer Motion scroll-triggered animations throughout
- **Dark Theme** — Elegant dark UI with glassmorphism cards and gradient accents
- **Skills Section** — Animated progress bars with a scrolling tech marquee
- **3D Project Cards** — Mouse-tracking tilt effect on project cards
- **Timeline Experience** — Alternating timeline for work and education history
- **Contact Form** — Functional contact form with loading states
- **Fully Responsive** — Works on all screen sizes
- **Smooth Navigation** — Fixed navbar with smooth scroll and active state tracking

## 🛠️ Tech Stack

- **React 19** + Vite
- **Three.js** via `@react-three/fiber` + `@react-three/drei`
- **Framer Motion** — page animations
- **GSAP** — utility animations
- **React Icons** — icon library

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
